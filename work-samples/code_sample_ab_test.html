What This Script Does

This automation script handles repetitive data cleaning tasks for A/B test analysis: merging telemetry logs, standardizing column names, applying validation rules, and exporting clean datasets for downstream modeling and reporting. It reduces manual overhead and ensures consistent formatting across experiments.

Code Excerpt


import pandas as pd

def clean_experiment_data(filepath):
    df = pd.read_csv(filepath)

    # Standardize column names
    df.columns = (
        df.columns
        .str.lower()
        .str.replace(" ", "_")
        .str.replace("-", "_")
    )

    # Drop empty rows
    df = df.dropna(how="all")

    # Apply validation rules
    df = df[df["participant_id"].notnull()]

    return df
