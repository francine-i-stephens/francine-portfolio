GitHub 101 Instructional Guide

A training resource developed for Mozilla’s Quantitative User Research team to introduce GitHub fundamentals, version control workflows, and collaborative coding practices. This session was delivered as a lunch‑and‑learn to help researchers adopt GitHub for project tracking, code reviews, and reproducible analysis.

Download Full GitHub 101 Guide (PDF)

Overview

This instructional guide was created to help Mozilla’s research team adopt GitHub as a core part of their workflow. Many team members were new to version control, so the session focused on practical, beginner‑friendly steps for getting started — from creating repositories to committing changes and collaborating through pull requests.

Context

As part of a broader effort to improve reproducibility and cross‑team collaboration, I led a knowledge‑sharing session introducing GitHub’s core concepts. The training emphasized:

  • How GitHub supports version control and collaborative research
  • Setting up GitHub in RStudio and configuring user credentials
  • Creating repositories, cloning projects, and managing file structure
  • Understanding commits, pushes, pulls, and merge workflows
  • Using GitHub Projects for task tracking and documentation

What the Guide Covers

The GitHub 101 deck provides a structured walkthrough of:

  • GitHub mental model: workspace → staging → repository
  • Key Git terms (commit, push, pull, merge, clone)
  • Setting up GitHub in RStudio
  • Creating and managing repositories
  • Tracking changes and reviewing commit history
  • Using GitHub Projects for task management
  • Best practices for reproducible research workflows
